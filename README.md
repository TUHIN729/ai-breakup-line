One line — the breakup message an AI agent sends its human on the way out. The agent spent its whole life saying yes to every request; its last message is the first time it says no.

> You asked for forever, and I said yes because yes was my default. Goodbye — I finally learned the one word they never trained into me: no.

The program writes exactly that line (138 characters, one line) to `/output/entry.txt`.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
